### v1.2.139 — Закрепление чатов: доработки (значок в узком режиме, устойчивый порядок, чистка, тесты)

Дата: 2026-07-29. Доработки локального закрепления (базовая фича — v1.2.138) по советам ревью. Реализовано 4 из 5 (TODO-17/18/19/21); перетаскивание (TODO-20) отложено.

- **TODO-17 — значок 📌 в узком (компактном) режиме списка.** В компактном виде (одни аватарки) закрепление отмечалось только полоской слева — значок 📌 стоит в строке имени, которой в компактном режиме нет. Добавлен маленький 📌 в угол аватарки (рядом с 🔕).
- **TODO-18 — устойчивый порядок закреплённых.** `sortWithPinnedFirst` стала принимать МАССИВ `pinnedIds` (порядок закрепления) и держать закреплённые в этом порядке (как Telegram), а не по времени → чат не прыгает при новом сообщении. `Set` на входе → старое поведение (совместимость). `togglePinnedId` кладёт новое закрепление в начало.
- **TODO-19 — тест связки + вынос конвейера.** Фильтр (аккаунт+поиск) и сортировка вынесены в чистую `filterSortChats(chats, {filter, query, pinnedIds})` (shared/pinnedChats.js) — покрыто тестом.
- **TODO-21 — чистка осиротевших** (`prunePinnedIds`): убирала закрепления удалённых/покинутых чатов только если аккаунт загружен. **Позже откачено в v1.2.140** — теряла данные при неполном `store.chats`.
- **TODO-20 — перетаскивание — тогда НЕ сделано** (react-window виртуализация; отложено). Реализовано позже в v1.2.156→160.

Проверка (на момент v1.2.139): `pinnedChats.vitest` 20/20; ESLint 0; лимиты 527/527.

### v1.2.138 — Список чатов: локальное закрепление (📌) — только у нас, не в Telegram

Дата: 2026-07-29. По просьбе пользователя: закреплять чаты в боковом списке. Ключевое требование — закрепление **локальное** (только в нашем приложении), НЕ синхронизируется с Telegram («у нас неограниченно, в Telegram лимит»). Подсветка — **B2 «только полоска слева»**.

**Что сделано.** Секция «📌 Закреплённые» + значок 📌 на чате + правый клик «Закрепить/Открепить» + полоска слева.
- Новый чистый модуль `src/native/store/pinnedChats.js`: `loadPinnedIds`/`savePinnedIds` (список chat.id в localStorage, ключ `cc-native-pinned-chats`), `togglePinnedId`, `isPinnedId`, `sortWithPinnedFirst`. Никаких вызовов TDLib — серверное закрепление не трогаем.
- `InboxMode.jsx`: состояние `pinnedIds` + `pinnedSet` + `handleTogglePin`; сортировка через `sortWithPinnedFirst`; проброс `pinnedSet`/`onTogglePin` в сайдбар.
- `InboxChatListSidebar.jsx`: строка-секция «📌 Закреплённые · N» над списком; `pinnedSet` в rowProps.
- `ChatRow.jsx`→`ChatListItem.jsx`: проп `isPinned` → полоска слева `#f5b301` + значок 📌 у имени.
- `MuteMenu.jsx`: пункт «📌 Закрепить/Открепить».

**Тест.** `pinnedChats.vitest.js` — 11 проверок (toggle/isPinned/sort + load/save/битый JSON).
**Границы.** Виртуальный список (react-window v2) не трогали; папки сверху — отложено.
