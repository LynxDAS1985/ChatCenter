### v1.2.387 — Ozon: НАСТОЯЩИЙ корень — парсер счётчика схлопывал секцию 'rv' (отзывы) в 'msg' (счётчик отзывов вставал на «Сообщения»)

**КАК РАБОТАЕТ / крайние случаи**: `s='rv'`→rv, `s='qa'`→qa, `s='msg'`→msg, `s='xxx'`(неизвестная)→msg (как было). **ОСТОРОЖНО (тех-долг):** тест-файл `.cjs` ПЕРЕ-реализует парсер (не импортирует ESM) → при правках парсера синхронизировать ОБЕ копии, иначе тест зелёный, а прод сломан. **Откат**: `git checkout src/utils/consoleMessageParser.js src/__tests__/consoleMessageParser.test.cjs`.

### v1.2.386 — Ozon: счётчики разделов ведут ТОЛЬКО фоновые страницы (передняя вкладка «застревала» — msg=3 при 0 сообщений)

**ЗАЧЕМ**: жалоба (скрин+журнал) — на кнопке 💬 «Сообщения» в виджете «3», хотя непрочитанных сообщений нет; пользователь ждал «3» на ⭐ «Отзывы» (реально 3 новых отзыва). Передняя вкладка Ozon показывает ОДИН раздел за раз; сторож гейтится по адресу и при уходе с раздела просто выходит, НЕ обнуляя счётчик → значение «застревает» (была на «Сообщениях», посчитала 3, ушла — msg висит 3). Фон свою 0 повторно не шлёт (гвард «только при изменении»), поэтому foreground-3 не перетирается. Отзывы (rv) из фона шли верно, но их перекрывала застрявшая msg.

**ЧТО** ([consoleMessageHandler.js](src/utils/consoleMessageHandler.js)): передняя вкладка Ozon больше НЕ ведёт счётчики разделов — сигнал `__CC_OZON_COUNT__` в foreground-обработчике ГЛОТАЕТСЯ (без `setOzonCounts`). Авторитетны ТОЛЬКО скрытые фоновые страницы (bg messenger/questions/reviews через [ozonBgWatcher.js](src/utils/ozonBgWatcher.js)) — каждая ВСЕГДА на своём разделе, счётчик не дрейфует/не застревает. `setOzonCounts` убран из деструктуризации consoleMessageHandler (стал не нужен). **КАК РАБОТАЕТ / крайние случаи**: msg=0 при отсутствии непрочитанных (фон messenger); rv=число новых отзывов (фон reviews); qa=вопросы без ответа (фон questions). Прочтение сообщений на вебе → фоновая messenger видит unread↓ → счётчик обновится. **Требование**: фоновые страницы должны грузиться (они и так основа слежки, TODO-36). **Откат**: `git checkout src/utils/consoleMessageHandler.js`.

**КАК ПРОВЕРЕНО**: `npm run lint` 0; `fileSizeLimits` 599/599; `ozonBgWatcher.vitest` 11/11; `consoleMessageParser` 29/29; полный `vitest`. **Требует перезапуска + ручной проверки**: 3 новых отзыва → «3» на ⭐ (не на 💬); 💬 = число реальных непрочитанных сообщений (0, если их нет).
