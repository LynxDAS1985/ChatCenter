### v1.2.146 — Удаление аккаунта без следов: проброс переименования на экран + чистка кэш-файла (3 из 4 доработок)
При удалении аккаунта оставались следы. Сделано: (а) канал `tg:account-renamed` пробрасывает переименование временного `tg_pending_X → tg_<userId>` на экран (убирает призрачную метку-фильтр); (б) `removeAccountCacheFile` чистит `tg-cache-<id>.json`. НЕ сделано осознанно: переименование папки сессии на диске (TDLib держит файлы открытыми, на Windows повредит вход). Файлы: `nativeStoreIpc.js`, `tdlibBackend.js`, `tdlibChatActions.js`, `tdlibIpcBridge.js`. См. [[code-todo]] TODO-23.

### v1.2.145 — Фикс: удаление аккаунта оставляло папку сессии → аккаунт-призрак воскресал при старте
КОРЕНЬ: `removeAccount` удалял папку по ПЕРЕИМЕНОВАННОМУ id, а папка названа id создания (`accountSubdir`). Фикс: брать `record.params.accountSubdir` для удаления папки сессии. Файл: `tdlibBackend.js`.

### v1.2.144 — Безопасность: маскируем код входа Telegram в файле логов
Код подтверждения входа мог попасть в `chatcenter.log`. Добавлена `maskLogSecrets` ([logger.js]) — маскирует цифры рядом со словами «код/code» в контексте входа; вызывается в `writeLog`. Тест `logMask.vitest.js`. Телефон маскируется до последних 2 цифр, пароль/код в лог НЕ пишутся.

### v1.2.143 — ДИАГНОСТИКА+страховка: чёрный экран после добавления 2-го аккаунта
Добавлены логи `[acct-*]` (add/remove/auth/update/ipc/store) + обёртка `<ErrorBoundary name="NativeInbox">` вокруг `InboxMode` в `NativeApp.jsx` (ловит падение рендера, пишет в лог). ErrorBoundary оставлен НАВСЕГДА (польза), диагностика — временная (см. [[code-todo]] TODO-22). Корень чёрного экрана найден позже в v1.2.147 (застрявший `loginFlow=success`).

### v1.2.140 — Фикс по ревью: убрана авто-чистка закреплений (теряла данные)
Пробная `prunePinnedIds` (v1.2.139) удаляла закрепление, если чата нет в `store.chats` — но `store.chats` часто НЕПОЛНЫЙ (кэш-подмножество на старте + `tg:chats append=false` заменяет порцией) → живой чат временно отсутствует → пин стирался навсегда. Авто-чистка УБРАНА. Безопасная чистка требует ЯВНОГО события удаления чата от TDLib. См. [[code-todo]] TODO-21, грабля в [[electron-core]].
