### v1.2.132 — Уведомления (native): имя автора в карточке из группы + чистка мёртвого дубля

Дата: 27 июля 2026. Первая часть была закоммичена ранее как `8ce3cf4` без версии (параллельная работа держала package.json).

**1. Заголовок карточки = имя АВТОРА (в группе — не название группы).** `title = message.senderName || chat?.title || 'Telegram'` ([nativeStoreIpc.js]). Для лички/канала совпадает с названием чата; при незагруженном чате — имя автора вместо «Telegram». TDLib 1.8.64: `sender_id` = messageSenderUser|messageSenderChat → оба резолвятся в `senderName`.

**2. Чистка мёртвого дубля `pickNotifTitle`.** Правило было вынесено в чистую функцию + 4 теста, но живой код применял ту же строку inline (файл на лимите), а функция нигде не вызывалась = мёртвый код, тест давал ЛОЖНУЮ уверенность. Найдено на ревью, удалено; живой заголовок покрыт прямым тестом `nativeStoreMutedNotify.vitest.jsx`. Renderer −12 строк.

**Не затронуто:** аватар автора (остаётся аватар группы, отдельная задача); мьют «по умолчанию для групп». Проверка: линт 0; helpers+muted 48/48.

### v1.2.130 — Список чатов (Вариант 1): время сообщения + имя отправителя в группах/форумах + значок форума

**Задача (макет «Как в Telegram»).** (A) время последнего сообщения справа на линии имени; (B) для групп/форумов имя автора цветом перед превью («Мария: текст»); (C) значок 🗂️ для форума вместо общего 👥.

**Что сделано.** Время — новый util [formatChatListTime.js] (сегодня→HH:MM, вчера→«вчера», неделя→день недели, старше→DD.MM.YY). Имя отправителя — поле `lastMessageSenderName` (ТОЛЬКО group + входящее); резолв в `getAccountChats` ([tdlibClient.js]) + inline в живом пути `tg:new-message`. Значок форума — `typeIcon` различает `chat.isForum`→🗂️ и группу→👥. Раскладка: бейдж непрочитанных переехал на линию превью (справа), на линии имени — время.

**Edge/тесты.** Нет last_message → время/префикс пусто; исходящее/канал/личка → без префикса; анон-админ → `chatDisplayName`; поиск не сломан (`chat.lastMessage` чистый). Тесты `formatChatListTime.vitest.js` (6), `mapChatLastSender.vitest.js` (5), снапшоты `ChatListItem` обновлены; renderer-бюджет 31150→31300.

**Файлы.** `formatChatListTime.js` (new), `ChatListItem.jsx`, `tdlibMapper.js`, `tdlibClient.js`, `nativeStoreIpc.js`, тесты + снапшот.
