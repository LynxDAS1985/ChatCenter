### v1.2.270 — Карточка аккаунта: разумный z-index (по ревью) [ОЖИДАЕТ ВИЗУАЛЬНОЙ ПРОВЕРКИ]

Дата: 2026-08-14. По придирчивому ревью v1.2.269. `AccountContextMenu` z-index понижен `100001 → 9999` (уровень попапа, как `MuteMenu`/`ForwardPicker`): выше содержимого и разделителей списка/рейла (`zIndex:6`), но НИЖЕ полноэкранных модалок (`ThemePicker`/`ContactCardModal` = 100000) — иначе модалка, открытая поверх карточки аккаунта, уходила под неё. **Важно (гипотеза, не воспроизведено вживую):** прошлый бамп v1.2.269 (1000→100001) для жалобы «полоса-разделитель поверх карточки» — по разбору кода БЕСПОЛЕЗЕН: карточка аккаунта — позиционированный сосед `native-content` ([NativeApp.jsx:417](../src/native/NativeApp.jsx#L417)), а разделители (`ChatListResizeHandle` z6, рейл-разделитель) лежат ВНУТРИ `native-content` → карточка (z1000) уже была выше них по правилам наложения; изолирующих `transform/filter/isolation` у родителей нет. Видимая «полоса» — вероятно СОБСТВЕННАЯ правая неон-рамка карточки (добавлена в v1.2.268), а не сторонний разделитель; для точного диагноза нужен запуск.
