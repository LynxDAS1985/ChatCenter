Для групп/каналов строки нет (username там не применим). Телефон по-прежнему только при наличии.

### v1.2.240 — Заметка о клиенте — в строке статуса шапки чата (полный текст в подсказке)

Дата: 2026-08-13. По просьбе (выбран вариант «вместе со статусом»): заметку о клиенте, которую оператор пишет в карточке контакта, теперь видно в ШАПКЕ открытого чата — в строке статуса рядом с «был(а) недавно». Раньше заметка жила только внутри карточки → во время переписки её не видно.

**Как работает:** [InboxChatPanel.jsx](../../src/native/components/InboxChatPanel.jsx) читает заметку активного чата `getContactNote(activeChat.id)` ([contactNotes.js](../../src/native/utils/contactNotes.js), localStorage, ключ `cc:contact-note:{accountId}:{rawId}`) и в строке статуса выводит «`был(а) недавно` · 📝 `<заметка>`» золотистым (#ffd479). Не влезает → обрезка `text-overflow:ellipsis`, а ПОЛНЫЙ текст показывается во всплывающей подсказке при наведении (атрибут `title`, факт уровня 1 MDN). Клик по заметке открывает карточку для правки. **Обновление:** заметка перечитывается при перерисовке шапки; после правки в карточке она закрывается (`setShowContact(false)`) → шапка перерисовывается → заметка обновляется (живьём во время набора в карточке — не обновляется, это ожидаемо). **Дублирования в саму карточку НЕ делаем**. Только показ (чтение localStorage + отрисовка), хранилище не менялось. Нет заметки → строки нет. Проверки: линт 0, полный vitest 2284/2284, лимиты 572/572. **Требует визуальной проверки**. Откат: убрать блок заметки в строке статуса + импорт `getContactNote` + `contactNote` + версия на 1.2.239.

Временная диагностика удалена. Файл: `max.hook.js` (300/300). Проверки: `node --check` OK, лимиты 572/572. **Требует ПОЛНОГО перезапуска + визуальной проверки.** Ограничение (гипотеза): если МАКС метит мьют совсем неочевидно — не поймаем; тогда в логе нет `mute-skip` → доработаем маску.
