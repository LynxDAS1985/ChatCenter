# Архив changelog — v1.2.156 … v1.2.160 (сага «перетаскивание закреплённых», ОТКАЧЕНА)

Перенесено из `features.md` 2026-07-30. Вся эта серия — попытки сделать ручное перетаскивание порядка закреплённых чатов. **Итог: ОТКАЧЕНО в v1.2.161** — пользователь уточнил, что закреплённые должны просто быть наверху ОБЩЕГО списка и листаться вместе с ним, а не быть отдельным блоком; живое перетаскивание же требует именно отдельного не-виртуального списка. Здесь — история попыток (для уроков). Актуальное поведение — `features.md` v1.2.161, [[code-todo]] TODO-20 (снято).

Урок (грабля): «перетаскивание порядка» и «строки в общем виртуальном списке react-window» несовместимы без замены/надстройки над react-window (он ставит строки по индексу-слоту, `key=index`, плавно переставлять нельзя).

### v1.2.160 — Перетаскивание «как в Telegram»: живой блок за курсором + соседи расступаются (ОТКАЧЕНО v1.2.161)

Закреплённые вынесены из виртуального списка в отдельный НЕ-виртуальный компонент `PinnedChatList.jsx` с перетаскиванием на Pointer Events (нажал → `setPointerCapture`; ведёшь → живой блок едет `translateY(dy)`, соседи съезжают `±ROW_H` с `transition`; отпустил → новый порядок). Порядок видимых применялся к полному `pinnedIds` через `movePinnedByVisibleOrder` (не-видимые при фильтре оставались на местах). **Проблема, приведшая к откату:** отдельный список рендерился ВНЕ прокрутки общего списка → закреплённые «приклеены», не листались вместе со списком. Заголовок «📌 Закреплённые · N» на этом шаге убран (по просьбе пользователя).

### v1.2.159 — Убрана «прозрачная копия» строки → чистый пустой слот (на HTML5-drag, до выноса)

Перетаскиваемая строка на месте показывалась полупрозрачной копией (`opacity .35`) — выглядело как «битый прозрачный блок». Заменено на чистый пунктирный слот. (Ещё на механике HTML5 drag в общем списке, до v1.2.160.)

### v1.2.158 — Красивее «поднятая» карточка + мягкий слот + курсор-рука (HTML5-drag)

Образ перетаскивания: клон строки в обёртке с полем 22px (чтобы `setDragImage` не обрезал тень), многослойная тень + золотая рамка закрепа. Курсор grab/grabbing. Честное ограничение: react-window (index-slot) не даёт соседям плавно разъезжаться.

### v1.2.157 — «Современный» вид: свой снимок за курсором + живая перестановка (HTML5-drag)

Свой чёткий образ через `DataTransfer.setDragImage` вместо полупрозрачного призрака браузера; живая перестановка по `dragOver` (сторона до/после — по середине строки, `reorderPinnedId(from,to,after)`). Поднятая строка гасла (`opacity`).

### v1.2.156 — Перетаскивание закреплённых (первая версия, HTML5 drag) + доводки по ревью

Первая реализация TODO-20: нативный HTML5 drag-and-drop на закреплённых строках ChatRow (`draggable`, `dragStart/dragOver/drop`), чистая `reorderPinnedId`, `handleReorderPin` в InboxMode, подсветка места сброса. Доводки по ревью к v1.2.155: уведомление берёт цвет-грань только если у чата есть `accountId`; полоса цвета аккаунта в узком режиме оставлена осознанно.

**Все функции этой серии (`PinnedChatList`, `reorderPinnedId`, `movePinnedByVisibleOrder`, `handleReorderPin(ned)`, DnD в ChatRow) удалены в v1.2.161.** Что СОХРАНИЛОСЬ из этих версий: доводки цвета уведомления (v1.2.156) и цвет-полоса в узком режиме — они не про перетаскивание.
