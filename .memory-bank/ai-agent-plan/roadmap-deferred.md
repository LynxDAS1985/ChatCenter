## 🚀 Большие задачи (Phase 4.4 / Phase 5)

Это серьёзные новые фичи, **новые версии** v1.2.0+.

### Phase 4.4 — Ollama (локальный LLM) ⭐⭐⭐

| Что | Зачем | Сложность |
|---|---|---|
| **Ollama integration** | AI без интернета. Бесплатно. Конфиденциально (данные не уходят наружу). | 2-3 часа |

**Что нужно**:
- Новый adapter `main/ai/adapters/ollamaAdapter.js`.
- Endpoint: `http://localhost:11434/api/chat` (по умолчанию).
- Format: близко к OpenAI tools, но без API key.
- UI: поле «URL Ollama» в Settings → AI вместо apiKey.
- Тесты с mock fetch.

**Почему хорошо**: одна семья опытных юзеров уже могут себе позволить локально запускать Llama 3 / Mistral. Для бизнеса с строгими требованиями к данным — единственная опция.

**Что юзер увидит**: 5-й вариант в Settings → AI: «Ollama (локально)». Указать URL → AI работает без интернета.

### Phase 5 — другие мессенджеры в Native режиме

#### Phase 5.1 — WhatsApp Business API ⭐⭐⭐

| Что | Зачем | Сложность |
|---|---|---|
| **WhatsApp через official Business API** | AI работает в WhatsApp как в Telegram | 10-15 часов |

**Что нужно**:
- Регистрация WhatsApp Business Account (требует верификации Meta).
- API: Webhook от Meta + REST API для отправки.
- Новый backend `main/native/backends/whatsappBackend.js` с теми же доменами что tdlib (auth/chats/messages/media).
- AdapterFromWA для tools: `getMessages`/`sendMessage`/`markAsRead`.
- Адаптер в `aiAgentBackendAdapter.js`.
- UI: вкладка «WhatsApp Native» рядом с «ЦентрЧатов».

**Сложность**: WhatsApp Business требует одобрения Meta (~1-7 дней). API лимитированный. Стоит денег после free tier (1000 conversations/мес бесплатно).

#### Phase 5.2 — VK API ⭐⭐

| Что | Зачем | Сложность |
|---|---|---|
| **VK через Long Poll API** | AI в VK сообществах и диалогах | 8-12 часов |

**Что нужно**:
- VK API token (vk_api_v5.131+).
- Long Poll сервер для real-time сообщений.
- Backend `vkBackend.js` с messages.send/getHistory/markAsRead.
- UI вкладка VK Native.

**Плюс**: VK хорошо документирован, есть Node SDK (`node-vk-sdk`).

#### Phase 5.3 — Viber API ⭐⭐

## 🔵 Известные ограничения (НЕ баги, документировано)

### ГигаЧат не делает параллельные tool calls

OpenAI/Anthropic могут вернуть 3 tool_calls за раз. ГигаЧат — **один** function_call. Поэтому ГигаЧат в **2-3 раза медленнее** для сложных задач (история + поиск + ответ = 3 итерации vs 1).

### Streaming ГигаЧат не поддерживает function_call

Документация Сбера это явно говорит. Tool use возможен только в non-streaming режиме. У нас уже так и реализовано — не баг.

### Webview мессенджеры (WhatsApp Web / VK / Telegа) не поддерживают AI tools

Сделано **специально** — write tools для AI работают **только в native_*** (TDLib пока). См. `aiPermissionGuard.js` scope check.

**Когда исправится**: Phase 5 — native backends для WhatsApp Business / VK / Viber.

### Auto-reply не показывает прогресс в UI

Дизайн: auto-reply задуман **тихим**. См. v1.1.2 раздел deferred. AIActivityDashboard показывает уже выполненные действия (журнал), не realtime.

### Master switch — global для всех правил

Нет per-rule switch — есть только enabled поле в каждом правиле. Master switch отключает **все** правила сразу. Per-rule control через `enabled` чекбокс в карточке.
