# Журнал багов и инцидентов по версиям — ChatCenter

В этой папке ведётся учёт **всех багов и инцидентов**, найденных или исправленных в проекте, с разбивкой по версиям.

---

## 🎯 Назначение папки

1. **Единый реестр багов**: каждый баг получает номер (`BUG-xxx`), статус, описание проблемы, причину и способ исправления.
2. **Связь с версиями**: для каждой версии фиксируется список закрытых и обнаруженных дефектов.
3. **Защита от регрессий**: документируются ловушки, чтобы будущие доработки не возвращали старые баги.

## 📋 Формат карточки бага

```markdown
### BUG-XXX: <Краткое название>
- **Версия**: vX.Y.Z
- **Важность**: 🔴 Критическая / 🟡 Средняя / 🟢 Косметика
- **Компонент**: <Файл или модуль>
- **Симптом**: Что видит пользователь / что ломается
- **Первопричина (Root Cause)**: Почему это происходило в коде
- **Исправление**: Что конкретно изменено
- **Тесты и доказательства**: Команда проверки / тест
- **Статус**: ✅ Исправлено / 🟡 В процессе / ❌ Открыто
```

## 📏 Правила и лимиты

- Каждый файл версии держится в пределах **100 КБ** (правило `memoryBankSizeLimits.test.cjs`).
- Ссылки на файлы репозитория оформляются относительно расположения файла: `](../../src/...)`.
- Все созданные файлы должны быть зафиксированы в git (`git add`), чтобы не ломать проверки целостности.
