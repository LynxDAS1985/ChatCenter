### BUG-008: Зависание очереди активных запросов чатов TDLib в inFlightMap
- **Версия**: v1.2.513
- **Важность**: 🔴 Критическая
- **Компонент**: `main/native/backends/tdlibBackendHelpers.js`
- **Симптом**: При определенных сценариях переключения аккаунтов или параллельных запросов чатов конкретный аккаунт переставал обновлять свои чаты с сервера TDLib до перезапуска приложения.
- **Первопричина (Root Cause)**:
  1. В ветке `if (accountId && inFlightMap?.has('__all__'))` создавался производный промис `pAll`, который регистрировался в `inFlightMap.set(key, pAll)`, но не содержал `.finally(() => inFlightMap?.delete(key))`. Ключ аккаунта навсегда оставался в памяти.
  2. При синхронном завершении `(async () => {})()` (например, пустой список аккаунтов) внутренний блок `finally { inFlightMap?.delete(key) }` отрабатывал синхронно ДО строки `inFlightMap.set(key, promise)`. Зарезолвленный промис помещался в карту уже после попытки удаления и блокировал все последующие вызовы.
- **Исправление**:
  - В ветке ожидания `__all__` добавлен блок `.finally(() => inFlightMap?.delete(key))`.
  - Для основного промиса `.finally(() => inFlightMap?.delete(key))` навешен на внешний промис `cleanPromise` до помещения в `inFlightMap`.
- **Тесты**: `main/native/backends/tdlibBackendHelpers.vitest.js` (17 тестов, включая тесты на синхронный выход и параллельный запуск).

### BUG-009: Пропуск загрузки чатов при пакетном добавлении аккаунтов
- **Версия**: v1.2.513
- **Важность**: 🟡 Средняя
- **Компонент**: `src/native/modes/InboxMode.jsx`
- **Симптом**: Если в состояние единого списка чатов за один тик добавлялось 2 или более аккаунтов, чаты подгружались только для последнего из них, а промежуточный оставался пустым.
- **Первопричина (Root Cause)**: Условие `store.accounts[store.accounts.length - 1]?.id` рассчитывало строго на прирост по одному аккаунту.
- **Исправление**: Условие точечной загрузки изменено на `store.accounts.length === prev + 1`. При приросте более чем на 1 вызывается `store.loadChats(undefined)`, загружая чаты для всех добавленных аккаунтов.
- **Тесты**: `src/native/modes/InboxMode.vitest.jsx`.

### BUG-010: Разгрузка PhotoSendModal.jsx и предупреждение лимита строк
- **Версия**: v1.2.513
- **Важность**: 🟢 Косметика
- **Компонент**: `src/native/components/PhotoSendModal.jsx`
- **Симптом**: Тест `fileSizeLimits.test.cjs` выдавал предупреждение о превышении 80% лимита файла (543 строки из 600).
- **Исправление**: Стили `photoModalStyles` и вспомогательные функции `buildRotatedFile`, `autosize` вынесены в `src/native/utils/photoSendUtils.js`. Размер `PhotoSendModal.jsx` уменьшен до 427 строк (71% лимита), предупреждение снято.
- **Тесты**: `src/native/components/PhotoSendModal.vitest.jsx` (15 тестов), `node src/__tests__/fileSizeLimits.test.cjs`.
